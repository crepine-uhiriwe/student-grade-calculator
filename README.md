# Student Grade Calculator

A beginner-friendly Python project that calculates student marks, total, average, grade, and pass or fail status.

## Features
- Collects student name.
- Accepts marks in three subjects.
- Validates marks between 0 and 100.
- Calculates total and average.
- Assigns a grade.
- Displays PASS or FAIL.

## Technologies Used
- Python

## How to Run
```bash
py student-grade-calculator.py
```

## Grading Scale
- 80–100: A
- 70–79: B
- 60–69: C
- 50–59: D
- Below 50: F
